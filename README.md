# Exercices C#

Exercices réalisés dans le cadre d'un cours d'apprentissage du C# (.NET 10).

## Exercices

| Dossier | Description |
|---|---|
| [`premier_programme`](premier_programme/) | Demande le nom et l'âge de l'utilisateur avec validation des saisies (nom non vide, âge entier strictement positif), puis affiche un message de bienvenue et l'âge de l'année prochaine. |

## Lancer un exercice

Prérequis : [SDK .NET 10](https://dotnet.microsoft.com/download)

```bash
cd premier_programme
dotnet run
```
